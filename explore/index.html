EXPLORATIONS / 一天实验室

今天，好奇什么？

给一个问题半天到一天，留下一个小小的成果。也可以只做卡片里的八分钟起步。

12 个可探索的题目

科技01

同一个问题，两种搜索

为什么换一种说法，就找不到同一条信息？

4–5 小时一天小项目
展开探索步骤 ＋

带走一个成果
一张检索结果对照表

  1. 整理 20 条不含私人信息的公开短文本，写出 6 个检索问题。
  2. 手工按词匹配，再按含义相关性排序；比较漏掉和误选的内容。
  3. 为每个问题写下判断相关的标准，尝试一个反例。
  4. 画出你理想中的搜索流程，标记哪些环节值得进一步实现。
只想试 8 分钟？

选一段公开文字，写出字面不同、意思相同的 3 个问题。

这是检索思路实验，手工语义排序不等于嵌入模型的真实评测。

科技02

给一个任务画出边界

一个助手应该在什么时候停下来问人？

3–4 小时一天小项目
展开探索步骤 ＋

带走一个成果
一张带失败分支的任务流程图

  1. 选一个虚构任务，例如为读书会整理公开书目信息。
  2. 列出输入、允许使用的资料、最终交付物和停止条件。
  3. 模拟资料缺失、内容冲突、工具失败三种情况。
  4. 补齐每种失败的恢复动作，用纸笔走一遍流程。
只想试 8 分钟？

给一个常见任务写下三条“什么时候算完成”。

不连接真实账户，不执行购买、发信或其他外部操作。

科技03

把一个界面减到刚好

去掉哪些元素，任务反而更清楚？

4 小时一天小项目
展开探索步骤 ＋

带走一个成果
一组前后对照的界面草图

  1. 选一个熟悉的界面，只定义一个用户任务。
  2. 画出完成任务必须经过的步骤，标记迟疑的位置。
  3. 用纸笔重画，合并重复信息，明确主操作。
  4. 自己隔一小时再用一次，记录仍然不清楚的地方。
只想试 8 分钟？

给一个页面上的每个按钮标注它帮助用户做什么。

草图是设计练习；没有实际用户验证时，不声称体验已经改善。

社会04

一条街的停留理由

什么样的空间让人愿意慢下来？

3–5 小时一天小项目
展开探索步骤 ＋

带走一个成果
一张不标私人路线的观察地图

  1. 选一个方便到达的公共空间，观察座椅、树荫、噪声与步行连续性。
  2. 挑两处不同位置，各记录十分钟的空间使用情况。
  3. 画示意图，只记录环境，不拍可识别的路人。
  4. 写出一个设计假设，并说明天气、时间等可能影响判断的因素。
只想试 8 分钟？

观察一处公共座椅：谁能方便坐下，谁不太方便？

公开成果不要带居住地点、精确日常路线或他人可识别信息。

社会05

一条规则会改变什么

同一个目标，为什么会催生不同的行为？

3–4 小时一天小项目
展开探索步骤 ＋

带走一个成果
一张参与者与激励关系图

  1. 虚构一个社区图书交换活动，列出组织者、借阅者和捐书者。
  2. 设计两条不同的借阅规则，分别推演可能行为。
  3. 寻找钻规则空子或让弱势参与者不便的情况。
  4. 修改规则，并列出还需要收集的证据。
只想试 8 分钟？

给一个日常规则写出一个预期效果和一个意外效果。

推演只是提出假设，不是实际人群行为的因果证据。

社会06

同一件事的两个版本

叙述者的选择，怎样改变故事的重心？

4–5 小时一天小项目
展开探索步骤 ＋

带走一个成果
一份来源对照笔记

  1. 选择一件范围很小的历史事件，找到两份可核对出处的公开材料。
  2. 分别标注时间、人物、直接证据与作者判断。
  3. 找出两份材料共同确认与互相冲突的部分。
  4. 写 300 字说明：目前能确认什么，还有什么待查。
只想试 8 分钟？

在一段历史叙述里，用两种颜色分出事实陈述和评价。

不要因为两篇文字观点不同，就默认它们证据同样可靠。

人文07

把电影听一遍

不看画面时，声音还讲了多少故事？

3–4 小时一天小项目
展开探索步骤 ＋

带走一个成果
一张声音与情绪的时间线

  1. 选择自己合法观看的一段 5–10 分钟电影片段。
  2. 正常观看，记录三个印象最深的时刻。
  3. 只听声音，再静音看画面，比较各自传递的信息。
  4. 画出对话、环境声、音乐与沉默的变化，并写下解释。
只想试 8 分钟？

闭眼听一分钟片段，写下你推测的空间与动作。

公开笔记使用自己的描述，不上传未经授权的影视片段。

人文08

沿着一段文字散步

作者究竟让你看见了什么？

3 小时一天小项目
展开探索步骤 ＋

带走一个成果
一页细读笔记与 200 字练习

  1. 选择一本手边的书，找一段令你停下来的描写。
  2. 标记感官细节、句子节奏，以及被省略的信息。
  3. 换一种视角写同一个场景，不照搬原句。
  4. 对照两版，解释哪一个细节改变了阅读感受。
只想试 8 分钟？

从一段文字里挑出最具体的一个名词。

分享时以原创分析为主，避免大量转载原文。

人文09

让两个观点坐在一起

不同答案，是否其实回答了不同问题？

4 小时一天小项目
展开探索步骤 ＋

带走一个成果
一张观点、前提、反例对照表

  1. 选一个具体问题，例如“好生活是否一定需要成就”。
  2. 找两份观点不同、出处清楚的公开原文或节选。
  3. 为各自写出最有说服力的版本，再找一个反例。
  4. 标出你的判断依赖什么前提，允许结论保持开放。
只想试 8 分钟？

把一个你赞同的观点改写成可被反驳的句子。

区分原作者主张与你的解释，不把不同立场简化成标签。

生活10

一小关里的选择

一个游戏怎样教会玩家下一步？

3–4 小时一天小项目
展开探索步骤 ＋

带走一个成果
一张关卡引导拆解图

  1. 选择自己拥有的游戏，体验一个范围很小的关卡。
  2. 记录第一眼看见什么、尝试了什么、如何收到反馈。
  3. 找出无需文字解释也能读懂的提示。
  4. 用纸画一个新关卡，只教会玩家一个动作。
只想试 8 分钟？

暂停游戏，找出正在引导你方向的三个视觉线索。

不把个人体验概括为所有玩家的体验。

生活11

收藏一种颜色的变化

同一种颜色，在不同光线里还是同一种吗？

3 小时一天小项目
展开探索步骤 ＋

带走一个成果
一张六格色彩观察板

  1. 选一个日常物体，在不同光线下观察。
  2. 记录色相、明暗和背景对比，不追求设备或参数。
  3. 用纸笔或绘图工具做出六格近似配色。
  4. 为每格写一个感受词，比较哪些描述来自光线，哪些来自联想。
只想试 8 分钟？

在房间里找三个相近颜色，排出明暗次序。

观察结果受设备、环境与个人感知影响。

生活12

给安静画一张地图

没有音乐时，周围仍然有什么节奏？

2–3 小时一天小项目
展开探索步骤 ＋

带走一个成果
一张声音分层图

  1. 在一个安全的日常场景静听十分钟。
  2. 把声音分成近处、远处、持续和偶发四类。
  3. 换一个场景再听，比较哪些声音更容易吸引注意。
  4. 用线条画出声音的节奏，写下最意外的发现。
只想试 8 分钟？

静听一分钟，数出五种声音。

无需录音；不记录可识别的私人谈话。

这些是供选择的练习题目，不是已经完成的个人经历。不需要打卡，也不需要全部做完。
